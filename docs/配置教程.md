# 配置教程：让 Codex 完成后给微信发消息

下面的账号、密钥、OpenID 都由你在微信官方页面获取。本教程不需要，也不会要求你把这些值发给项目作者或贴到公开 Issue。

## 1. 安装通知器

把源码解压到一个固定目录，例如 D:\Codex-WeChat-Notifier。双击 INSTALL.cmd。它会为当前 Windows 用户安装 Codex Stop Hook；若已有 hooks.json，会先备份到本项目运行时生成的 backups/。

安装后保留该目录。想换位置时，请在新位置重新运行 INSTALL.cmd，并检查旧 Hook 是否仍在 Codex 的 Hook 列表里。

## 2. 申请微信接口测试号

打开微信公众平台官方测试号页面：

<https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login>

用自己的微信扫码登录。在页面中找到：

- **appID**：测试号的应用 ID。
- **appsecret**：测试号密钥。不要截图、发聊天或写进仓库。
- **测试号二维码**：用接收通知的微信扫码关注。
- **用户列表中的 OpenID**：关注后，从对应用户行复制。**不要填测试号名称里的 wxid_…**。

关注后，在微信中打开这个测试号的资料页，点右上角 **「···」→「设为星标」**。看到菜单变成「取消星标」就表示设置成功。星标能让测试号更容易找到，但不保证通知有声音；是否响铃仍取决于微信和手机系统的通知设置。

界面示意（以下都是虚构占位符，不是真实账号）：

~~~
测试号信息
  appID       <你的 appID>
  appsecret   <你的 appsecret>

测试号二维码 → 用户列表
  昵称        <你的微信昵称>
  OpenID      <你的 OpenID>   ← 复制这一项
~~~

## 3. 新建消息模板

在同一页面的“模板消息接口”区域新增测试模板。标题可填“Codex 完成通知”，模板内容粘贴以下五行，字段名必须原样保留：

~~~text
{{first.DATA}}
项目：{{project.DATA}}
时间：{{time.DATA}}
结果：{{content.DATA}}
{{remark.DATA}}
~~~

保存后复制新生成的**模板 ID**。它不是 appID，也不是 OpenID。

你也可以双击 OPEN-WECHAT-SETUP.cmd：它会打开官方页面并把上面的模板复制到剪贴板。扫码和复制四项参数仍需你亲自完成。

## 4. 在本机保存配置

双击 MANAGE.cmd，选择“配置/更换微信官方测试号”，依次输入 appID、appsecret、OpenID、模板 ID。输入 appsecret 时不会显示字符。

这些值会由 Windows DPAPI 加密保存在本机 config/。换 Windows 用户或电脑时不能直接搬运加密文件，须重新配置。**即使已加密，也不要上传该文件。**

如果误把测试号名称 wxid_… 填成 OpenID，双击 FIX-OPENID.cmd，按提示从“测试号二维码 → 用户列表”重新复制。

## 5. 测试、信任与开启

1. 双击 TEST.cmd，在微信里查看是否收到测试模板消息。
2. 确认收到后，在 Codex 中检查新 Hook 的命令确实指向你的 notify.ps1，然后信任它。Codex CLI 可用 /hooks 查看和信任。修改 Hook 定义后可能需要再次信任。[OpenAI Docs：Hooks](https://learn.chatgpt.com/docs/hooks)
3. 重启 Codex，使当前会话加载 Hook。
4. 双击 ON.cmd 开启自动通知。让 Codex 完成一轮短任务，再在微信核对。
5. 不需要时双击 OFF.cmd。TEST.cmd 可以在关闭状态下单独测试。

测试号消息可能只在公众号会话中显示红点，没有普通好友消息的声音提示。
