# 故障排查

## 测试消息能收到，但 Codex 完成后没有

1. 确认已双击 ON.cmd。MANAGE.cmd 可查看开关状态。
2. 在 Codex 检查 Stop Hook 是否加载、是否已信任；修改过 Hook 命令后须重新信任。
3. 重启 Codex 后再完成一轮任务。安装或修改 Hook 前已启动的会话可能仍使用旧配置。
4. 检查本机 logs/notifier.log 和 state/last-result.json。这些文件可能含项目名或消息摘要，发求助帖前要脱敏。

## 微信返回 invalid openid

通常是把 wxid_… 测试号名称当成 OpenID。到官方测试号页面“测试号二维码 → 用户列表”复制关注用户的 OpenID，再运行 FIX-OPENID.cmd。

## 微信显示乱码

本项目的 notify.ps1 显式按 UTF-8 读取 Hook JSON，并按 UTF-8 发送模板内容。确认使用的是最新脚本，且微信测试模板字段名与教程一致。Windows PowerShell 默认编码不同，删掉这些编码设置可能使中文和 JSON 解析失败。

## 有消息但没有声音

公众号模板消息的呈现由微信客户端决定。星标公众号和开启“接收文章推送”不保证模板消息响铃。本项目无法修改微信客户端的提醒类别。

## 注意发布隐私

错误日志、微信截图和“已配置”压缩包都可能暴露账号或工作内容。公开提问时只提供**自己手工脱敏**后的错误码和步骤，不附配置文件。
