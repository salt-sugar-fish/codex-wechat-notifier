# Codex 微信完成通知器（Windows）

Codex 每轮工作结束时，通过微信公众平台接口测试号给关注该测试号的微信用户发一条模板消息。使用官方接口，不需要第三方推送中转平台。通知默认关闭，可用双击文件开启或关闭。

> 本项目只负责“Codex → 微信”的完成通知。它不能读取个人微信聊天，也不能把微信回复自动送回 Codex 对话。

## 为什么做这个

说实话，找了一圈通知方案，不是额度不够、要花钱，就是还得装别的 App 或折腾中转，挺不方便的。我其实只想在 Codex 干完活时收到一条微信通知；看到消息后远程连回电脑，直接在原来的对话框里继续聊就行了。简单点，够用就好。

## 快速开始

1. 把本项目解压到你希望长期保留的目录，例如 D:\Codex-WeChat-Notifier。安装后不要随意移动目录，否则 Hook 路径会失效。
2. 双击 **INSTALL.cmd** 安装 Codex 的 Stop Hook。脚本会备份已有的用户级 hooks.json，并保留其他 Hook。
3. 按 [详细配置教程](docs/配置教程.md)申请自己的微信接口测试号，创建消息模板并填写四项配置。
4. 双击 **TEST.cmd**，确认微信收到测试消息。
5. 在 Codex 中检查并信任新 Hook，重启 Codex；再双击 **ON.cmd** 开启通知。

完成通知只显示在公众号会话中。是否响铃由微信客户端和系统通知策略决定，本项目无法把公众号消息变成普通好友消息。

## 文件与开关

| 文件 | 用途 |
| --- | --- |
| INSTALL.cmd | 安装/更新 Codex Stop Hook |
| OPEN-WECHAT-SETUP.cmd | 打开测试号页面、复制模板并进入配置向导 |
| TEST.cmd | 实发一条测试通知，不改变开关 |
| ON.cmd / OFF.cmd | 开启 / 关闭自动完成通知 |
| MANAGE.cmd | 菜单方式管理 |
| FIX-OPENID.cmd | 仅修正填错的 OpenID，并重新测试 |

通知器以脚本所在目录为数据目录，配置、日志和状态分别保存在运行时生成的 config/、logs/、state/ 中。配置由当前 Windows 用户的 DPAPI 加密；换电脑或换 Windows 用户要重新配置。Codex 用户目录中的 hooks.json 只存放指向本脚本的命令。

## 隐私和公开发布

**不要上传实际运行目录或自己的“已配置”压缩包。** 其中可能含有加密配置、错误日志、项目名和消息摘要。公开仓库只放本目录列出的源码和教程，不放 config/、logs/、state/、backups/、微信截图或二维码。.gitignore 是额外防线，发布前仍要人工检查文件清单。

本仓库的示例不包含真实 appID、appsecret、OpenID、模板 ID、微信 ID 或账号截图。教程统一使用 <你的…> 占位符。若密钥曾公开，请到微信公众平台更换，并重新配置。

## 工作原理

Codex 的 Stop Hook 把本轮信息以 UTF-8 JSON 送给 notify.ps1。脚本先检查开关、按 turn ID 去重，然后用微信接口测试号获取 access_token 并发送模板消息。失败原因写到本地日志，不阻止 Codex 正常结束。

Codex 的非托管 Hook 必须经用户检查并信任；修改 Hook 定义后可能需要重新信任。见 [OpenAI Docs：Hooks](https://learn.chatgpt.com/docs/hooks)。

## 使用范围

- Windows PowerShell 5.1、已安装的 Codex、网络可访问微信官方接口。
- 需要你自己的微信公众平台接口测试号。测试号的可用性、发送规则由微信决定。
- 个人开发和测试用途。不要将模板消息当作必达告警。
